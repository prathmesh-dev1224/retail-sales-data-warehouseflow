# Retail Sales Data Warehouse

## Overview

End-to-End Retail Sales Data Warehouse built using PostgreSQL.

## Architecture

Raw Layer → Staging Layer → Warehouse Layer → Analytics Layer

## Features

- Data Modeling
- Star Schema
- Fact & Dimension Tables
- SCD Type 2
- Incremental Loading
- ETL Audit Framework
- Query Optimization

## Tech Stack

- PostgreSQL
- SQL
- PL/pgSQL
- GitHub

## Dataset

Brazilian E-Commerce Dataset (Olist)
